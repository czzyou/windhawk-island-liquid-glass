# 向内折射玻璃试用计划

目标：接近用户提供的液态玻璃折射方案，制作本地试用版。

1. 在 `native-glass/src/renderer.cc` 替换原边缘凸起及内部形变：中心不变形，边缘向内采样，位移按 `1.1 × 边宽 × (1 - 深度/边宽)^2.6` 衰减。边宽取 `max(4px, min(44px, 短边/3.5))`；短边不足 32px 时跳过折射。
2. 红、绿、蓝分别取基础位移的 115%、100%、85%。在现有原生 GPU 管线实现，不加入浏览器或 SVG。更新 `native-island-glass.h` 和 `panel.h` 的色散参数。
3. 保持布局、文字自适应、着色、模糊及边缘光；只评估折射差异。取消旧的多点扩散采样，避免把新折射抹糊。
4. 在 `build.py` 更新现有玻璃检查：实际着色器编译、折射方向、中心平整、边缘强度、尺寸/DPI 和对称性。原来限制不得折叠的断言不适用于此方案。
5. 运行 `python build.py --release`，生成源码及 x64/x86 DLL，完成项目检查。复用本地安装脚本，备份源码、注册表和 DLL 指向，管理员切换并确认进程及玻璃就绪，失败回退。

完成标准：本地构建和检查通过，试用版安装并启动；实际视觉效果由用户确认。本次不提交、不推送、不发布。

## 试用后的定稿

用户认可向内折射后，将色散收敛为 ±3%（红/绿/蓝位移 103%/100%/97%），内部清晰混合比例调整为 80%，最外缘保持 100%；左上高光系数为 0.10，右下补光为 0.015。用户随后明确授权发布，正式版本为 1.5.15，按仓库发布流程执行。
