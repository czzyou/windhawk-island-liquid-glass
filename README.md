# 灵动岛 · 液态玻璃

基于 Himanshu / devcode90 的 Dynamic Island for Windows 修改，使用 Windhawk 运行，液态玻璃后端来自 hicccc77/electron-liquid-glass。保留原作者及第三方 MIT 许可证。

**构建与测试声明：** GitHub Actions 负责自动编译、回归检查和生成试用包，维护者作为首位体验测试者。自动检查通过不代表界面、动画和交互已经实机验证；体验确认并明确授权发布后，才在本机签名并发布正式 Release。

## 安装

支持 Windows x64、本机管理员账号和 Windhawk **1.7.3 安装版**。需要先安装并运行 Windhawk；本项目无需提交或通过 Windhawk 官方模组库安装。

1. 从 [Releases](https://github.com/czzyou/windhawk-island-liquid-glass/releases/latest) 下载 `island-setup.zip`。
2. 解压，关闭其他已启用的灵动岛模组，再双击 `install.cmd`，接受首次管理员授权。
3. 安装器从本仓库下载已签名源码并在本机编译，完成后启用。首次主队选择约在启动 45 秒后显示，也可从右键菜单设置。

默认英文、数字使用 **SF Pro Text**，岛内中文优先使用 **苹方**。字体需用户自行安装，公开仓库和安装包不包含字体文件；缺少字体时使用系统回退，见[字体安装说明](fonts/README.md)。

安装更新器约 1 分钟后触发首次检查，之后每 **3 小时**静默检测。无更新不提示；有更新只在灵动岛外侧边缘显示静态黄色叹号，不弹窗、不抢焦点、不自动安装。休眠时不主动唤醒电脑，失败后不立即重试。

**已有用户需重新运行新版 `install.cmd` 一次以升级更新器到 1.0.2、替换计划任务。** 普通插件更新无法替换旧更新器脚本或修改其检测频率。

按住 **Alt＋鼠标左键** 可拖动灵动岛，松开左键后记住位置。手动放置后暂停自动标题栏避让，避免被拉回。

文件托盘默认开启，拖入文件暂存路径，单击打开、按住拖出。点击 **×** 后，本机普通文件加入七天删除清单：到期永久删除原文件，不进回收站。七天内重新拖入可取消；修改或替换过的文件不会删除。清单保存在本机，重启后继续，到期时未运行则下次启动补查；文件被占用时延后重试。文件夹仅移除入口，右键清空也仅移除入口。

右键灵动岛 → **检查更新…** 可随时手动检测；黄色叹号出现时菜单改为 **安装可用更新…**。只有手动操作才下载、校验签名、编译并切换，保留天气城市、NBA 主队、日程和外观设置。忙碌时推迟安装，完成后再手动更新。

**Roll back previous version** 回退上一版；**Uninstall updater** 只移除更新机制，保留插件与个人数据。

此首版已验证构建、签名、数据保留及模拟回退；尚未在第二台电脑完成首次安装、计划任务和真实重启的全流程验证。现有手动导入版和自用版不会自动被迁移或覆盖。

## 媒体、歌词与快捷查词

- **跨播放器切换**：同时存在多个系统媒体来源时，展开媒体页底部显示来源按钮，点击临时切换；有新来源开始播放时恢复自动规则。右键 → **媒体来源（选择后锁定）** 可锁定某个播放器，或选择自动跟随。播放、切歌与进度条控制当前选中的来源。播放器需提供 Windows 系统媒体会话；同一应用按来源归类，不承诺区分每个浏览器标签。
- **实时歌词**：展开后滚轮切到歌词页，保留原展开尺寸，文字左对齐并自动换行，当前句位于中间、上一句在上、下一句在下，以明暗区分；媒体页内仅显示当前句以避开控制区。右键可开启 **收起时显示歌词**、**媒体页内显示歌词** 或 **歌词页置顶**。歌词页滚轮始终切换功能页，同步歌词自动跟随，纯文本歌词静态显示。收起时按当前歌曲最长一句的实际宽度在 320–400 逻辑像素内计算，超长句从句首滚动。普通浏览器视频不查歌词，切回已缓存歌曲直接恢复。歌词来自 LRCLIB，查询会发送歌名、歌手、专辑和时长；匹配结果缓存在本模组存储目录，默认上限 25 MB，可在设置中关闭或右键清除。无同步歌词时收起视图显示歌名。右键 **歌词同步** 可分别微调蓝牙与扬声器／有线的时序偏移。
- **进度与音量**：Apple Music 进度条通过客户端 UI Automation 控件兼容拖动，客户端更新可能影响可用性。音乐页右侧小喇叭打开系统音量滑条，调节后 1 秒返回，按住拖动时保持显示。
- **快捷查词**：按 **Alt+Space** 打开输入框，输入单词或短语后按 Enter；也可选择剪贴板文字或最近查询。方向键选择、Esc 关闭，再次按快捷键也可关闭。单词优先查英文 Wiktionary，dictionaryapi.dev 备用；百科结果来自英文 Wikipedia。结果保留英文释义，中文译义由 [MyMemory](https://mymemory.translated.net/doc/spec.php) 提供并标注机译；免费服务有额度限制，暂不可用时保留英文。只在提交查询后联网，最近记录仅存内存，不自动记入单词本。快捷键可在设置中修改，右键也有 **快捷查词…** 入口。

## 修改与发布

参与开发请先阅读 [贡献指南](CONTRIBUTING.md)，其中说明了源码修改、Actions 检查和 PR 提交方式。

GitHub Actions 在推送代码、提交 PR 或手动触发时自动运行两项检查：`Source check` 验证补丁合成、版本格式和设置 YAML；`Windows build` 使用固定 Windhawk 1.7.3 工具链编译 x64/x86、运行回归及发布检查，并生成保留 30 天的 `island-build-提交号` 试用包。维护者先进行实际体验；Actions 不签名、不自动发布。

固定操作见 [发布流程](发布流程.md)：推送源码后由 Actions 构建，维护者先试用，明确授权发布后再本机签名并发布正式 Release。只 push 代码不会让使用者收到更新。

日常发布使用现有签名密钥，不需要重新初始化。更新版本和说明，生成源码并提交、推送；等待当前提交的两项 Actions 检查成功并完成首轮体验，用户明确要求发布后运行：

```powershell
# 复用当前提交的 Actions 成功结果，在本机签名和打包，不重复编译
powershell -NoProfile -File updater/publish.ps1 -PrepareOnly
# 上传草稿，附件齐全后发布为 Latest 正式版
powershell -NoProfile -File updater/publish.ps1 -PublishPrepared -NotesFile RELEASE_NOTES.md
```

已有公钥对应的私钥只在原维护者 Windows 用户配置中存在；参与开发的人可以修改源码并提交 PR，无法冒用原维护者签名。发布新版本必须严格提高三段数字版本号。签名密钥不可丢失或替换；备份说明见 [更新器文档](updater/README.md)。

```powershell
python build.py --release
python release-checks.py
powershell -NoProfile -File updater/test.ps1
# 额外验证更新器实际调用本机编译器，输出仍在隔离目录
powershell -NoProfile -File updater/test.ps1 -Compile
```

公开仓库仅分享给熟人不构成访问限制。客户端不需要 GitHub 账号、Token、Git、Python 或 GitHub CLI。日志和回退备份仅保存在本机。
