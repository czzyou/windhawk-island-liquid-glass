# 灵动岛字体安装说明

- `SF-Pro-Text-Medium.otf`：英文、数字，字体族为 SF Pro Text。
- `PingFangSC-Light.ttf`：中文，当前文件的 Windows 字体族名为“苹方_常规”，排版族名为 PingFang SC。

公开仓库和安装包不包含字体文件。用户需自行准备有权使用的字体，手动安装。

选中这两个字体文件，右键选择“安装”，然后重新启用灵动岛。英文、数字的默认设置为 SF Pro Text；中文优先使用苹方。
