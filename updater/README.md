# 灵动岛自动更新

本包用于 Windhawk 1.7.3 安装版、x64 Windows，使用者需要本机管理员账号。Windhawk 必须已安装并运行。

首次解压后双击 `install.cmd`，接受一次 Windows 管理员授权。若 Windows 阻止来自网络的文件，先确认安装包由维护者提供，再在 ZIP 的属性中解除锁定并重新解压。

字体由用户手动安装，公开安装包不包含字体文件。英文、数字默认使用 SF Pro Text，岛内中文优先使用苹方；未安装时回退系统字体，个人字体设置保留。

更新器 **1.0.2** 改为每 3 小时静默检测。已有 1.0.1 使用者需重新运行新版安装包的 `install.cmd` 一次，普通插件更新不会替换旧更新器或计划任务。

如果已经启用了其他灵动岛，请先在 Windhawk 中关闭它；安装器不会替你停用或覆盖其他模组。自动更新版使用独立的 `local@dynamic-island-liquid-glass` 标识，旧模组数据不会自动迁移。

安装约 1 分钟后触发首次检查，之后每 3 小时检测一次；相邻自动网络检测至少间隔 3 小时，不主动唤醒电脑，失败后也不立即重试。

自动检查只读取并验证更新信息，无更新不提示；有更新仅显示黄色叹号，不弹窗、不编译、不重启灵动岛。

右键灵动岛 → **检查更新…** / **安装可用更新…** 可手动下载、校验、编译并启用新版，手动操作的结果会弹窗显示。

开始菜单 `Windhawk Island` 中保留：

- `Roll back previous version`：回到上一版本，阻止马上重装该版本。
- `Uninstall updater`：移除自动检测任务和更新器，保留插件、个人设置和回退备份。

手动更新的编译期间旧版继续使用；切换时灵动岛会短暂重启。正在计时或编辑日程时推迟安装，结束后可手动再操作。断网或检查失败后等待下一轮三小时检测或手动触发。

更新会验证维护者的 RSA 签名和源码 SHA256。保留天气城市、主队、日程和外观设置。手动禁用的插件不会被更新器启用。手动修改过受管理源码时停止覆盖并提示。

日志：`%ProgramData%\Windhawk-Island-Updater\update.log`；编译失败详情在同目录的对应版本临时子目录中。上线前须经过其他电脑验证；当前不声明支持 ARM64、便携版或其他 Windhawk 版本。

## 维护者

发布配置在根目录 `release.json`。推送源码后由 GitHub Actions 完成 x64/x86 编译、自动检查和试用包；维护者作为首位体验测试者，实际体验与自动检查分开确认。明确授权发布后，才通过 `updater/publish.ps1` 在本机核对检查结果、签名并发布正式版。普通代码提交、试用产物、草稿和预发布不会推送给客户端。

首次执行 `powershell -NoProfile -File updater/publish.ps1 -InitializeKey` 创建签名密钥；私钥保存在当前用户 LOCALAPPDATA 的 `Windhawk-Island-Publisher/signing-key.dpapi`，使用 Windows DPAPI 绑定当前账号，不能提交到 GitHub。此文件单独拷贝到其他账号不能直接恢复，请另外做好原 Windows 用户配置/恢复凭据的离线备份；不要删除或覆盖密钥。

先提交并推送源码，等待当前提交在 main 上的 `Source check` 和 `Windows build` 成功，完成首轮体验并获得发布授权。再执行 `powershell -NoProfile -File updater/publish.ps1 -PrepareOnly` 复用检查结果，在本机签名和打包；使用 `-PublishPrepared -NotesFile <版本说明路径>` 校验附件并发布，不重复本机构建。准备后修改源码或安装器时，需重新提交、通过 Actions 并准备附件。签名私钥留在本机；客户端仍下载签名源码并本机编译，无需登录 GitHub。
